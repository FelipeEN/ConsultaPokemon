POR DENTRO DO PROJETO

Documentação

Endpoints da PokéAPI

A aplicação utiliza dados reais de https://pokeapi.co/api/v2. O endpoint de Pokémon fornece medidas, imagens, habilidades, movimentos e estatísticas. A lista fornece o catálogo; tipo, espécie e cadeia de evolução complementam os detalhes.

GET /pokemon/{id|name}
GET /pokemon?limit=...&offset=...
GET /type/{name}
GET /pokemon-species/{id}
GET /evolution-chain/{id}

API Gateway

Todas as requisições passam por um único gateway JavaScript com funções para Pokémon, lista, tipos, espécie e evoluções. Ele valida respostas HTTP e JSON; a interface trata separadamente ausência de resultados, falhas de rede e dados opcionais indisponíveis.

Cache e favoritos

As respostas são reutilizadas em memória e no armazenamento local, com validade de 24 horas. Após esse prazo, a próxima consulta busca dados atualizados. Um serviço independente salva os números dos favoritos no navegador e sincroniza os botões da interface.

Como executar os testes

Abra a aba Testes e clique em Executar testes. Os testes são locais e não usam a rede: verificam conversões, normalização, validação de dados, paginação e operações de favoritos. O resultado de cada verificação aparece na própria página.
